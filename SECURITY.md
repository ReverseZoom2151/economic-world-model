# Security policy

Last reviewed: 2026-08-28.

## Supported versions

| Version | Support status |
| --- | --- |
| 0.2.x | Supported release line |
| Earlier versions | Not supported |

Security fixes are applied to the current supported release line. No response or remediation time
is guaranteed.

## Report a vulnerability privately

Use a private GitHub Security Advisory draft:

<https://github.com/ReverseZoom2151/economic-world-model/security/advisories/new>

If private vulnerability reporting is not enabled or the advisory form is unavailable, contact
[@ReverseZoom2151](https://github.com/ReverseZoom2151) through the GitHub profile without posting
sensitive details. Ask for a private coordination channel. Do not open a public proof of concept.

Do not disclose a suspected vulnerability in a public issue, pull request, discussion, test
fixture, or generated artifact. Include:

- the affected version or commit;
- reproduction steps or a minimal proof of concept;
- the expected impact and affected users;
- any known mitigations;
- whether the report or proof of concept may be shared with collaborators.

The maintainer will acknowledge the report through GitHub, investigate it, and coordinate a fix
and disclosure when warranted. Reports that concern a dependency may be coordinated with its
upstream project.

## Scope

In scope are vulnerabilities in source code, package and release automation, protocol loading,
artifact handling, and repository workflows. Publicly known vulnerabilities in dependencies are
also useful reports when they affect a supported installation.

Scientific disagreements, numerical accuracy reports without a security impact, and requests for
support belong in GitHub Issues under [SUPPORT.md](SUPPORT.md).
