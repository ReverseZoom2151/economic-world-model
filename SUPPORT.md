# Support

Last reviewed: 2026-08-28.

Use [GitHub Issues](https://github.com/ReverseZoom2151/economic-world-model/issues) for reproducible
bugs, installation problems, and bounded usage questions. Search existing issues before opening a
new one and use the provided issue forms.

Include the package version, Python version, operating system, minimal reproduction, complete error
message, and the result you expected. Remove credentials, private data, and local file contents that
you are not authorized to share.

This is a maintainer-supported open-source project. Response times, fixes, and compatibility with
unlisted environments are not guaranteed.

Do not use public support channels for suspected vulnerabilities. Follow [SECURITY.md](SECURITY.md)
and use GitHub Security Advisories instead.
